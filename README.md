# Notes Organizer

A browser-based productivity app that turns pasted notes into a clean summary, action list, and follow-up plan.

## Features

- Paste notes
- Generate a concise summary
- Extract action items
- Create a follow-up plan
- Browser-only demo

## How to run

Open `index.html` in your browser.

## Tech stack

- HTML
- CSS
- JavaScript

## Portfolio value

This project demonstrates productivity UX, text processing, clean interface design, and practical automation thinking.
